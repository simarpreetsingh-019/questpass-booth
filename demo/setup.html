Set up your booth

Design your booth here, save the settings file, and upload it to your copy of the repository. This page only makes a file on your device: it can't change anyone's booth.

Start from: the Pizza DAO theme · a blank booth · or load your saved file (Settings file → Load a file).

When it looks right: publish it
  1. Tap ⬇ Save settings file above. You get booth-base.json.
  2. Fork the repository on GitHub, if you haven't (your copy is yours to run).
  3. In your fork: Add file → Upload files, drop booth-base.json at the top, and commit.
  4. Settings → Pages → Source: GitHub Actions. For one booth per city, connect a spreadsheet too.
  5. Actions → pages → Run workflow. Your booths go live with just the booth on them: your guests never see this page.

Step-by-step guide: docs/pizzadao.md.
